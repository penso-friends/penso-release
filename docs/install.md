## 설치 파일 내려받기

홈 화면의 **다운로드** 섹션에서 사용 중인 OS에 맞는 설치 파일을 내려받아 실행합니다.

- **Windows**: `.exe` 설치 파일 (또는 포터블 버전)
- **macOS**: Apple Silicon(`arm64.dmg`) 또는 Intel(`x64.dmg`)

## 최초 실행 시 보안 경고가 뜰 때

무료 독립 배포 앱 특성상 최초 1회 보안 경고가 표시될 수 있습니다.

- **Windows**: "Windows의 PC 보호" 창에서 **추가 정보 → 실행** 클릭
- **macOS**: **시스템 설정 → 개인정보 보호 및 보안** 하단에서 **그대로 열기** 클릭
